# 中州养老 C++ 端 UI 复刻规格（基准 1280×720）v0.1

> 对应 Web 端：`zznursing-vue3-master`（RuoYi-Vue3 + Element Plus + ECharts）
> 用途：C++ 桌面端（OpenGL + ImGui + SQLite3）第一阶段复刻 **①应用框架 ②登录页 ③首页看板**
> 依据：源码逐行提取 + 本机真实运行渲染测量（1280×720 / 1024×768 / 1600×900 / 1920×1080），截图见 `assets/`
> 约束：**布局以比例/相对约束为主，像素仅作基准参考**；所有页面可随窗口缩放；默认窗口 1280×720、可缩放、允许 F11 全屏
> 版本：v0.1（2026-11-23）｜状态：待 C++ 团队评审 + lead 确认

## 1. 阅读约定

| 记号 | 含义 |
|---|---|
| `W / H` | 当前窗口客户区宽 / 高（单位：逻辑像素，与 ImGui 单位一致） |
| `S` | 侧边栏宽度：展开 **200**，折叠 **54** |
| `A` | 内容可用宽 = `W − S − 24 − 15`（左内边距 24、右内边距 15） |
| `g` | 卡片间距（gutter）：两栏 **24**，三栏 **12** |
| “基准值” | 1280×720 下的实测像素，仅用于对照验收，不要写死 |
| D-xx | 与 Web 端的已知差异项编号（见 §11） |

**ImGui 单位换算建议**：Web 1px ≈ ImGui 1.0f（96dpi 下）。若做 DPI 缩放 `s`，则所有尺寸、字号、间距统一 `×s`（`style.ScaleAllSizes(s)` + 字体按 `14×s` 像素加载）。不要混用“部分缩放”。

## 3. 应用整体框架（壳）

### 3.1 区域划分（1280×720 基准）

```
┌──────────┬────────────────────────────────────────────────────┐
│          │ 顶栏 Navbar                               高 50     │  y=0..50
│  侧边栏   ├────────────────────────────────────────────────────┤
│ Sidebar  │ 标签栏 TagsView                           高 34     │  y=50..84
│  宽 200   ├────────────────────────────────────────────────────┤
│          │                                                    │
│  y=0..720│ 内容区（可纵向滚动）                                 │
│          │ 可用宽 A = W−200−24−15                              │
│          │                                                    │
└──────────┴────────────────────────────────────────────────────┘
```

| 区域 | 基准像素 | 相对约束（必须按此实现） |
|---|---|---|
| 窗口 | 1280×720 | 默认；可缩放；最小建议 **1024×640**（低于此提示并限制）；F11 全屏 |
| 侧边栏 S | 200×720 | **宽固定 200**（=15.63%×W 基准，但不随 W 缩放）；高 = 100%H；可折叠为 **54** |
| 顶栏 | (W−S)×50 | 宽 = 100%−S；高固定 50（=6.94%×H 基准） |
| 标签栏 | (W−S)×34 | 宽 = 100%−S；高固定 34（=4.72%×H） |
| 内容可视区 | (W−S)×(H−84) | 宽 = 100%−S；高 = 100%−84；**内部纵向滚动** |
| 内容内边距 | — | 上 24、右 15、下 52、左 24（写死基准值，不随窗口缩放，属固定留白） |

> **C++ 建议（差异 D-01）**：Web 端顶栏+标签栏会随页面滚出（`fixedHeader=false`）。桌面端建议**顶栏与标签栏固定**、仅内容区滚动，更符合桌面习惯；若要 100% 对齐 Web，可做成配置开关。

### 3.2 响应式规则（窗口宽度变化）

| 窗口宽 W | 侧栏 | 内容布局 | 说明 |
|---|---|---|---|
| **≥1920**（xl） | 200 | 两栏 70.83% / 29.17%；底部三栏 **各 33.33%** | 1920 实测：左卡 1184、右卡 473、底部三卡各 552 |
| **1200–1919**（lg） | 200 | 两栏 70.83% / 29.17%；底部三栏 **29.17% / 29.17% / 41.67%** | 1280 实测：730.4 / 286.6；295.1 / 295.1 / 426.8 |
| **<1200** | 200 | **全部卡片单列**、宽 = A（1280→1024 时 785） | 1024 实测：7 张卡全部 785 宽，页面高 2056 |
| **<992** | 折叠 54（推荐）或抽屉 200 | 单列 | Web 为“抽屉+遮罩”；**差异 D-02**：桌面端建议直接折叠为 54 图标栏，不做遮罩抽屉 |

**高度变化**：卡片高度**固定**（237 / 278），不随 H 拉伸；H 变小 → 内容区出现纵向滚动条；H 变大 → 底部留白增大（内容总高约 901 + 顶部 84 = 985）。
**最小宽度**：建议 1024（低于 1024 仍可单列显示，但图表可读性差）；**最小高度** 640。

### 3.3 滚动策略

| 区域 | 策略 |
|---|---|
| 内容区 | 纵向滚动；滚动条宽 6px，轨道 #F1F1F1、滑块 #C0C0C0 圆角 3；不横向滚动 |
| 侧边栏 | 菜单独立纵向滚动（内容高 670，展开后 760 > 可视 636 时滚动） |
| 标签栏 | 标签过多时横向滚动（Web 用 ScrollPane；C++ 可用左右箭头或横向滚动） |
| 表格/弹窗 | 本期不涉及 |

### 3.4 ImGui 实现建议（结构伪代码）

```cpp
// 建议结构：主窗口 = 工作区，三块子区域用 BeginChild
ImGui::SetNextWindowPos({0,0}); ImGui::SetNextWindowSize(io.DisplaySize);
ImGui::Begin("##root", nullptr, ImGuiWindowFlags_NoDecoration | ImGuiWindowFlags_NoMove |
             ImGuiWindowFlags_NoBringToFrontOnFocus | ImGuiWindowFlags_NoScrollbar);
  // ① 侧栏（固定宽，独立滚动）
  ImGui::BeginChild("##sidebar", {S, 0}, false, ImGuiWindowFlags_NoScrollbar);
      DrawLogo();                       // 50 高
      BeginScrollableMenu();            // 侧栏菜单
  ImGui::EndChild();
  ImGui::SameLine(0, 0);
  // ② 右侧列
  ImGui::BeginChild("##right", {0, 0}, false, ImGuiWindowFlags_NoScrollbar);
      DrawNavbar();                     // 50 高（固定）
      DrawTagsBar();                    // 34 高（固定）
      ImGui::BeginChild("##content", {0, 0}, false, ImGuiWindowFlags_AlwaysVerticalScrollbar);
          DrawDashboard();              // 内容区（纵向滚动）
      ImGui::EndChild();
  ImGui::EndChild();
ImGui::End();
```

> 注意：卡片内部要用裁剪（`PushClipRect`）防止内容溢出卡片（Web 端就是 `overflow:hidden`）。若 C++ 端修正了 Web 的裁切缺陷（D-03），需在验收时注明。

### 7.3 ImGui 实现建议

- 背景图用纹理 `ImGui::GetWindowDrawList()->AddImage` 按 cover 计算 UV 裁剪（保持比例，居中裁剪）。

## 11. 与 Web 端的差异项（C++ 端建议 vs 照抄）

| 编号 | Web 现状 | C++ 建议 | 理由 |
|---|---|---|---|
| D-01 | 顶栏+标签栏随页面滚出（fixedHeader=false） | **固定顶栏+标签栏**，只滚内容 | 桌面习惯；可做配置项 |
| D-02 | <992px 侧栏变抽屉+遮罩 | 折叠为 54px 图标栏 | 桌面无触摸遮罩需求 |
| D-03 | 中间图表卡片固定 278 高、图表 234 被裁约 27px | 图表区按 200~210 实现，保证坐标轴完整 | 可读性优先 |
| D-04 | 个人卡问候昵称为空（取错字段）/昵称为空（store 未存） | 正常显示 `nickName` | 修 bug |
| D-05 | 记住密码存 Cookie（RSA） | 本地加密配置文件或系统凭据 | 桌面安全 |
| D-06 | 头像/下属员工/常用功能图标为 png | 可用占位图形/字体图标；若可复用 png 需确认素材来源 | 资源与版权 |
| D-07 | “本周”选中但日期区间显示今天 | 按当前选中项正确计算区间 | 修 bug |
| D-08 | 切换周后列表仍按“天索引”取数据 | 按“选中日期”取当日 3 条 | 行为更直观 |
| D-09 | 图表不随窗口 resize 重排 | 每帧或 resize 时按容器尺寸重绘 | 必须做 |
| D-10 | 菜单图标字段错乱 | 按语义映射图标 | 视觉正确 |
| D-11 | 顶栏含源码/文档/字号/布局设置等演示项 | 可隐藏，仅保留核心项 | 减负 |
| D-12 | 登录页账号密码预填 admin/admin123 | 建议保留（演示环境）或配置化 | 验收方便 |

> 差异项需在 C++ 端验收单中逐条勾选“按建议实现 / 按 Web 照抄 / 不实现”。

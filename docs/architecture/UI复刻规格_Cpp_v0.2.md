## 2. 列表页通用布局（所有业务页同一骨架）

```
内容区（x=200..W，y=84..H）
└── .app-container  padding: 20px（四周）
    ├── ① 搜索栏：白底、inline 表单、行高 32、行间距 28；末行为 搜索/重置 按钮
    ├── ② 工具栏：行高 32；左侧 新增/修改/删除/导入/导出（浅色按钮），右侧 刷新/列设置/搜索（32×32 圆形图标按钮）
    ├── ③ 数据表格：表头 40 + 数据行 49/50；可横向滚动（列多时）
    └── ④ 分页：高 32，右对齐，距表格 12~16
（长页面整体纵向滚动：1280×720 下分页常在视口下方，需滚动才可见）
```

相对约束：
- 内容可用宽 `A = W − 200（侧栏） − 40（左右 padding）`；表格宽 = A（100%）。
- 搜索栏/工具栏/表格/分页均占满 A；搜索项按“label 68 + 控件 240 + 项间距”自然换行。
- 表格列按文档给定宽度累计；总宽超过 A 时表格内部横向滚动（`el-table` 行为）。

## 3. 通用组件规格（实测 + ImGui 实现建议）

### 3.1 搜索栏（Query Bar）

| 项 | 基准值（1280×720） | ImGui 建议 |
|---|---|---|
| 容器 | 白底；padding 0；位于 `.app-container` 顶部（y≈104） | 用 `BeginChild("##search")`，背景白 |
| 表单项 | label 宽 68（右对齐、14px #606266）；控件宽 240、高 32；单项总宽 308 | `TextUnformatted` + `SetCursorPosX` 对齐；输入框使用 `InputText` 定制高度 32 |
| 行间距 | 28（控件底 → 下一行控件顶间隔；行距 60） | `Dummy({0,28})` |
| 搜索按钮 | 80×32，背景 #00B8A0，白字 14，圆角 4，前置放大镜图标 | 按钮自绘或 `Button` + `PushStyleColor` |
| 重置按钮 | 80×32，白底、#606266 字、边框 #DCDFE6，圆角 4，前置刷新图标 | 默认按钮样式 |
| 控件样式 | 输入框高 32（内层 30），边框 #DCDFE6，圆角 4，placeholder #A8ABB2；下拉框同高；日期范围同高 | `FrameRounding=4`，`FrameBorderSize=1` |
| 交互 | 回车触发搜索；清空按钮（clearable）出现在输入框右侧 | Enter 提交；`InputText` 加清空小按钮 |

|---|---|---|
| 新增 | 80×32，圆角 4，14px | 底 #E5F7F5，字 #00B8A0，边框 #7FDBD7（浅青主色） |

### 3.3 数据表格（Data Table）

| 项 | 规格 |
|---|---|
| 表头 | 高 **40**；背景 **#F8F8F9**；文字 **#515A6E**、**13px**、600；下边框 #EBEEF5；文字居中（多数列 `align="center"`） |
| 数据行 | 高 **49**（含单元格上下 padding 8）；正文 14px、#606266；行 hover 背景 #F5F7FA；无斑马纹 |
| 勾选列 | 宽 50，居中；仅用户/角色/岗位等批量操作页有 |
| 序号列 | `type=index`，宽 50（护理项目为 120） |
| 操作列 | 宽 150~200，居中；按钮为**文字链接**（14px、主色 #00B8A0），间距 8；或图标按钮（编辑/删除/钥匙/勾） |
| 空态 | 居中文字“暂无数据”（#909399） |
| 加载 | 表格区域遮罩 + 转圈（loading） |
| 溢出 | 列宽合计 > 容器宽时表格横向滚动；长文本列 `show-overflow-tooltip`（省略号+悬浮提示） |

**ImGui 建议**：用 `ImGui::BeginTable`（固定表头 `ImGuiTableFlags_ScrollY | ImGuiTableFlags_BordersInnerH`），行高 49、表头行高 40；自绘表头背景色与文字色；操作列按钮用主色文字按钮；空态时在表格中央 `SetCursorPos` 输出“暂无数据”。

## 7. 交互规范（列表页通用）

| 操作 | 行为 |
|---|---|
| 搜索 | 点击搜索/回车 → 重置到第 1 页 → 表格 loading → 结果刷新 |
| 重置 | 清空所有查询条件 → 重新查询 |
| 新增 | 打开空白弹窗（标题“添加 X”）→ 校验 → 确定提交 → 关闭 → toast“新增成功” → 刷新列表 |
| 修改 | 仅选中 1 条时可用（用户管理需勾选；房型/护理项目为行内按钮）→ 打开回填弹窗 → 提交 → toast → 刷新 |
| 删除 | 确认框 → 确定 → 调删除接口 → toast → 刷新 |
| 状态切换 | 开关/按钮 → 确认框（可选）→ 调 changeStatus → toast |
| 导出 | 请求文件流 → 浏览器下载；C++ 端可导出 CSV/XLSX（建议后续） |
| 分页 | 切页/改每页条数 → 重新请求 |
| 失败 | 顶部红色 toast 显示错误信息；表格保持原数据或空态 |
| 空数据 | 表格居中“暂无数据” |
| 加载 | 表格区域 loading 遮罩；按钮防重复点击 |
